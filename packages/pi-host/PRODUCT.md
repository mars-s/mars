# Mars

Mars is a portable Pi Durable agent with a Next.js chat interface. A clone installs
both workspaces from one pinned dependency lockfile. Native Pi owns conversations,
background tasks, model usage and recovery. The UI exposes image input, subthreads,
ordered workflows and catalogue-driven plugin management.

The owner controls the host VM. HTTP owner authentication, exact origin checks,
private external data, deferred discovery, bounded outputs and restart recovery
remain part of the product. A fresh clone includes no account state or user data.
