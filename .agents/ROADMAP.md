# Roadmap

The owner chose Pi Durable plus Mars UI as the sole active Mars implementation.
The replacement migration is tracked in EXECUTION-PLAN.md. Historical ZCode and
DeepSeek programme plans are superseded and remain in Git/private backups.

Before declaring migration complete, prove a clean clone install and real service
cutover with existing native state. Later product work builds on the existing
native extension/workflow/thread APIs, not the retired ZCode scheduler.
